# SoulVibe — сайт

Фронтенд сайта SoulVibe: главная страница, расчёт таланта и страница результата.
Сейчас это готовая вёрстка с анимациями и заглушками вместо серверной части — список того, что осталось подключить, ниже.

**Стек:** Vite 5, React 18, TypeScript, чистый CSS (без Tailwind и UI-библиотек). Шрифт — Onest (Google Fonts, подключён в `index.html`).

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # проверка типов + сборка в dist/
npm run preview   # посмотреть собранную версию
```

Нужен Node.js 20+.

## Страницы

| Адрес | Что это | Файл |
|---|---|---|
| `/` | Главная | `src/pages/Home.tsx` |
| `/raschet` | Расчёт таланта (форма) | `src/pages/Calc.tsx` |
| `/rezultat` | Результат расчёта | `src/pages/Result.tsx` |
| `/primer` | Пример результата (та же страница с плашкой «Пример») | `src/pages/Result.tsx` |

Маршрутизация своя, без библиотек — `src/router.tsx` (`Link`, `navigate`, переход к якорям `/#formats`).

  content.ts               ТЕКСТЫ и ССЫЛКИ сайта — менять здесь
  lib/

  components/

      EcosystemBeams       схема экосистемы с импульсами по линиям
      RoleFan              «Роль и персонаж» — веер карточек

    form/
      CityField            поле города с подсказками
    ui/                    общие мелкие элементы: иконки, кнопка с бликом, наклон карточки,
                           буквенная анимация заголовков (letters.tsx), вспышка рамки

Картинки из `public` в коде подключаются через `asset('/путь')` — так они работают и локально, и по подпути на GitHub Pages.

## Что осталось подключить

1. **Ссылки** — `LINKS` в `src/content.ts`: бот, Telegram, email, документы (сейчас заглушки, помечены `TODO`).
2. **Расчёт таланта** — в `src/pages/Calc.tsx` функция `run()` сейчас имитирует запрос (задержка и переход на `/rezultat`). Нужно отправить данные формы на сервер и показать полученную роль. Поля: пол, имя, дата рождения, время (необязательно, есть «Не знаю»), город.
3. **Город рождения** — `src/lib/cities.ts`, функция `searchCities`: заменить тестовый список на GeoNames (инструкция в шапке файла). В форме выбранный город хранится целиком: название, регион, страна, координаты, часовой пояс.
4. **Результат** — `src/pages/Result.tsx` показывает пример роли «Управленец» (`RESULT_MANAGER` в `content.ts`). Заменить на ответ расчёта. Тексты результатов заказчик пришлёт отдельно.
5. **Панель «Состояния»** на `/raschet` (слева внизу) — служебная, для показа состояний формы при согласовании макета. Перед запуском убрать (блок `review` в `Calc.tsx` и стили `.review` в `global.css`).
6. **Вариант секции «Роль и персонаж»** — по адресу `/?role=1` открывается прежний вариант (блоки вместо веера). Когда заказчик подтвердит веер, этот вариант можно удалить (`RoleCharacter` в `Home.tsx`).

Открытые вопросы к заказчику: нужна ли галочка согласия на обработку данных теперь, когда в форме нет email и Telegram; отдельное согласие на рассылку.

## Анимации — на что обратить внимание

- Появление блоков при прокрутке сделано через `IntersectionObserver` и класс `is-in`; если блок снова уходит вниз за экран, появление повторяется.
- Заголовки секций появляются и уходят по буквам — `ui/letters.tsx` (`letters()`, `useScrollParts()`).
- Все анимации отключаются при системной настройке «Уменьшить движение» (`prefers-reduced-motion`).

## Публикация

`.github/workflows/deploy.yml` собирает сайт и выкладывает на GitHub Pages при каждом пуше в `main`
(в настройках репозитория: Settings → Pages → Source: GitHub Actions). Сайт открывается по адресу `<логин>.github.io/<репозиторий>/`.
